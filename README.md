## 我在系统里做了什么

以下 11 个主题来自我 2025-05 至 2026-10 的全部提交记录归类，括号内为大致提交量与起始时间。

**1. 运营商产品 / 分组 / 号码管理与路由配置**（~500 次，2025-05 起，从零搭建）
系统的主干模块。实现运营商产品分组、号码长度与显示规则配置、路由重指（含超长校验），并让分组变更能通过定时任务处理"未来生效的路由切换"。后期把这块的判定逻辑收敛成可核对的口径（如分组级不通判定、无网关行的置灰与跳转约束）。

**2. 运营商 A→Z 自动化测试与群呼**（~60 次，2025-05 群呼 / 2025-09 起 A→Z）
服务端测试作业（`OperatorTestJob`）改动 47 次：支持按目的地方向批量拨测并回收结果，加了断电/异常后的重试续跑，用"锁定操作人"避免多人同时触发同一测试任务造成冲突，测试量与正显规则等边界条件逐轮收紧。

**3. 轮选价格管理与自动变价**（~100 次，2025-08 起）
实现轮选变价定时任务与每周一自动解锁任务，并补上 JOB 监控——变价作业本身有执行情况的可观测性问题，我把它的执行状态、失败告警做成独立维度。

**4. 客户单指 / 费率申请与 OA 工作流打通**（~140 次，2025-09 起）
客户单指申请页支持按国家 code 反查运营商并反选；费率核查页同时比对待变表、费率变更表与轮选表；修复了从 OA 工作流抓取单据的解析逻辑，让审批数据能自动落到系统里。

**5. IDR / IVR / CDR 话单数据采集与跨库同步**（~30 次，服务端首个任务 2025-06）
这是我在后端仓的第一项工作：新增 IDR 数据采集任务、自动拉取 IVR 并带翻译、CDR 拉取到 SQL Server 的定时任务，以及采集文件的删除与重跑管理。多数据库（SQL Server / MySQL / PostgreSQL）之间的数据搬运是这里的常态问题。

**6. 问题看板：从 WinForms 控件到 WebView2 的动态可配置看板**（~35 次，2026-06 自建）
自己设计并实现的模块：看板内容动态可配置，混线问题按当天数据展示并能一键发起到 OA 的处理流程；随后清理掉了被 WebView2 取代的废弃 WinForms 控件。这是我从"做功能"转到"做产品形态"的一块。

**7. 混线问题判定与核查**（~16 次，2025-12 起）
优化混线后缀处理与相关路由生成逻辑，处理 mix/generated 特殊情况，并把不参与核查的项目类型排除出亏损核查，减少误报。

**8. 连接质量分析（ConnectionAnalysis）**（~34 次，2026-07 起）
新增后拨号延迟（PDD）指标的统计与展示；修复交叉查询与分组模式下排序混乱的问题；在 SQL Server 严格 GROUP BY 下用 MAX 包裹字段做兼容。多维度（ASR / ACD / 分组）口径对齐是这个模块最难的部分。

**9. CDR 质量与风险分析、阈值告警**（~20 次，2026-04 起）
优化风险分析的根因检测逻辑，重点提升"客户切流"这类场景的识别准确度——质量指标骤降往往不是线路坏了而是客户侧流量迁移，误判会直接导致错误处置。

**10. AI 智能助手与排障技能包**（~15 次，2026-05 起）
在桌面端新增 AI 助手模块，把任务管理与 AI 对话结合；为话单查询工具编写 VOIP NOC 排障技能包，让"某路由 ASR 低"这类问题能按标准排障流程自动分析而不是只翻译错误码。

**11. 发布与工程基建**（~600 次发版记录）
桌面端通过 ClickOnce + FTP 分发，累计约 600 次发布提交，版本号自增到 4.8k 量级；服务端以 Windows 服务/控制台形式运行并按需部署。日常包含 NPOI 导出约定、项目结构与开发约定的文档化。
